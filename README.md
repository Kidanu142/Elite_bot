
# 🤖 Elite Telegram Payment Bot

Advanced Telegram bot for premium subscription payments with automated verification system.

## ✨ Features
- 💳 Tele Birr payment integration
- 📸 Automatic payment proof processing  
- 🔐 Secure verification codes
- 👨‍💻 Admin dashboard commands
- 📊 SQLite database storage
- 🔔 Real-time notifications
